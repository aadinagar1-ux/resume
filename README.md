# Aadi Nagar, Resume Website

My resume website for the Website Development course (IIMBx, BBA DBE).

Live: https://aadinagar1-ux.github.io/resume/

The site is the headquarters I haven't built yet: 4 floors, and every room is something I've done. On a big screen each floor slides sideways, every floor the opposite way to the one before, with a lift between floors. The motion button in the menu switches the movement off.

## What's in here

- `index.html` - the page, one section per room
- `style.css` - all the styling for the rooms
- `plan.css` - the sliding floors, the lift and what each room does as you arrive
- `script.js` - smooth scrolling, cursor, clock, the lift display, room links, the motion button and the small simulation in the research lab
- `gl.js` - the building drawn in dots behind my photo, with WebGL
- `resume.pdf` - one-page resume (printed from the page itself)
- the `.jpg` files - photos and certificates

Built with HTML, CSS and a small amount of JavaScript. No frameworks.
