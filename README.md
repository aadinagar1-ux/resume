# Aadi Nagar – Resume Website

My personal resume website, built with HTML and CSS for the Website Development course at IIMBx.

**Live site:** https://aadinagar1-ux.github.io/resume/

## About the design
The look is inspired by landonorris.com (Lando Norris is my favourite F1 driver): a dark background, one neon lime accent, big poster-style headings, and an "On Track / Off Track" split between work and life.

## What's inside
- `index.html` – the page
- `style.css` – all the styling (Google Fonts, colour variables, Flexbox, Grid, a mobile layout and print styles)
- `resume.pdf` – a one-page version of my resume, made by printing the site
- `photo.jpg`, `marathon.jpg`, `travel.jpg` – photos used on the site
